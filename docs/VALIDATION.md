# 验证记录

记录日期：2026-10-05。以下结果属于一台用户提供的普通 GR III，不能推广到所有硬件版本。

## 已有物理证据

- 用户确认已升级至菜单 Ver.2.10。
- 工厂入口文件及 Script Enable 生效，`script/startup.ttl` 能执行。
- 两次 GoodBye 原图导出均为7264字节，完整 SHA-256 匹配本次固件资源。
- 哈苏候选临时写入、原图备份、正式安装的读回分别完成完整哈希校验。用户确认相机正常显示，关闭脚本后可使用。
- 第一版麦当劳 stage1 的原图、哈苏当前图、哈苏备份及麦当劳临时图完整匹配。后续本地可访问读回记录表明当前资源为第一版麦当劳；用户反馈清晰度和计数栏遮挡。
- M6 缩小版临时写入的日志 error=0，所有文件与候选哈希匹配，但最终 JPEG 本身出现红底杂块。它没有覆盖当前图。这个例子表明“编码解码成功”与“视觉正确”不同，随后修正了量化表策略。

## 桌面检查

- 14项单元测试，包含 TTL 子集的独立控制流模型：导出不改内部资源、零字节载荷重建、备份保持、同名拒绝、重复开机不重写、备份失败停止、最终读回失败尝试回退、恢复读取对应备份、日志重复拒绝、完整哈希拒绝、路径注入拒绝、留空布局、禁止直接写存储卡、原图匹配限制。
- JPEG 严格 marker/长度/JFIF/SOF0/SOS 检查，Pillow 完整解码。
- 生成脚本载荷重新重建，与候选字节逐字节一致；行长、条件配对、前向跳转检查。
- 固件静态分析可由用户自行提供样本复现，公开仓库不放固件或机内原图。

测试模型不模拟真实相机解释器、闪存、断电、电源管理、镜头及菜单，不构成相机安全认证。

## 尚未验证

- 新桌面工具的完整公开流程及随机文件名模板在真实相机上整套运行。
- 单次开机组合安装、公开恢复包装的真实执行。
- 缩小上移修正版最终相机显示。
- Windows 图形界面、Windows 打包产物、Intel Mac 产物。
- 其他型号、固件、特殊版本相机。

## 发布门槛

当前适合 `v0.1.0-preview` 研究预览，默认采用分步流程。只有新工具完整流程、关闭脚本后显示以及对应恢复都完成物理验证，才能去掉这项预览说明。此前私人的“发布包”是整理好的操作文件，不等于已经获得公众版本兼容验证。
